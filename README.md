# Heart Disease Prediction System

Predicting 10-year risk of coronary heart disease using the Framingham Heart Study dataset.

## Model Performance
- Accuracy: 87.6%
- Precision: 88%

## Tech Stack
Python, scikit-learn, Pandas, NumPy, Matplotlib, Seaborn, Google Colab

## Features
- Data preprocessing with SimpleImputer and StandardScaler
- Logistic Regression model
- Confusion matrix visualization
- Classification report with precision, recall, F1-score
